## 1. Direct Seller Discovery

### 1.1 Amazon.ae Seller Scraping

**Method:** Scrape seller information from product listings

| Data Point | How to Get |
|------------|------------|
| Seller Name | Product page → "Sold by" |
| Storefront URL | amazon.ae/sp?seller=XXXXX |
| Product Count | Seller storefront page |
| Categories | Product listings |
| Ratings/Reviews | Seller profile |

**Tools:**
- Helium 10 (Amazon seller research)
- Jungle Scout
- Custom Python scraper (BeautifulSoup + Selenium)

**Process:**
1. Search top categories (Electronics, Fashion, Home, Beauty)
2. Extract seller IDs from first 10 pages of results
3. Visit each seller storefront
4. Filter for sellers with 50+ products (indicates serious business)
5. Cross-reference with Noon to identify multi-marketplace sellers

**Expected Yield:** 2,000-3,000 seller profiles

---

### 1.2 Noon Seller Discovery

**Method:** Browse Noon marketplace and extract seller info

| Data Point | How to Get |
|------------|------------|
| Seller Name | Product page → "Sold by" |
| Seller Badge | "Noon Fulfilled" vs "Partner Fulfilled" |
| Product Range | Browse seller's listings |

**Limitation:** Noon has less seller transparency than Amazon

**Workaround:**
- Focus on "Partner Fulfilled" sellers (they manage own inventory = need SoukHub)
- Check product pages for seller names
- Use Noon's category pages to find active sellers

---

### 1.3 Cross-Reference for Multi-Marketplace

**The Gold:** Sellers appearing on BOTH Amazon.ae AND Noon

**Method:**
1. Build Amazon seller list (name, products, categories)
2. Search each seller name on Noon
3. Match by:
   - Exact business name
   - Similar product catalog
   - Same brand names
4. Flag matches as "High Priority" leads

**Expected Multi-MP Sellers:** 500-1,000 verified matches
